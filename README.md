# Avatar Community App

[![CI Status](https://github.com/Mati54866/avatar-community-app/actions/workflows/ci.yml/badge.svg)](https://github.com/Mati54866/avatar-community-app/actions)

A mobile community application built with React Native (Expo), where users can create avatars and interact through posts, comments, likes, and voting features.

---

## 🚀 Features

- Avatar system (profile customization)
- Post creation, editing, and deletion
- Comments and nested replies
- Like and view count system
- Poll creation and participation
- Image upload (custom assets excluded from repository)
- Multi-language support (i18n)
- Push notifications
- Infinite scroll
- Optimistic UI update

---

## 🛠 Tech Stack

- React Native (Expo)
- Expo Router
- TypeScript
- React Query (TanStack Query)
- React Hook Form
- Day.js
- i18n (Internationalization)
- JWT Authentication
- Expo Push Notifications
- EAS (Build & Deployment)

---

## 🧩 Implementation Details

- Common reusable components
- Custom hooks pattern
- Server state management with React Query
- Form handling with React Hook Form
- Date handling with Day.js
- SVG usage and custom font integration

---

## ⚠️ Assets Notice

Avatar image assets are excluded from the repository due to copyright restrictions.
For local development setup, add your custom images to the `assets/images/` directory.

---

## 📋 Prerequisites

- Node.js (v18+)
- Yarn 4.0+
- iOS Simulator (macOS) or Android Emulator

## ⚙️ Installation & Running

```bash
# Install dependencies
yarn install

# Start development server
yarn start

# Run on specific platform
yarn ios        # iOS Simulator
yarn android    # Android Emulator
yarn web        # Web Browser
```
